# LIBRO: 100 Ejercicios de Python para practicar
## Autor: Laurentine K. Masson

Ejercicios sacados de este libro resueltos, partiendo del enunciado literal pero aprendiendo la arquitectura MVC desde estos niveles tan básicos y añadiendo cosas aprendidas sobre la marcha.

El índice del libro distribuye los ejercicios de la siguiente manera:
1. Ejercicios para principiantes: ejercicios nº 1 a nº 33
2. Ejercicios de nivel intermedio: ejercicios nº 34 a nº 74
3. Ejercicios avanzados: ejercicios nº 75 a nº 100
